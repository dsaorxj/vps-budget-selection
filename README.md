## 个人博客需要多高的配置？

答案：1GB 内存起步就够，预算宽裕选 2GB 更从容；硬盘 20GB 起步足够；流量基本不用操心。

先看程序层面的差异。同样是“写博客”，不同系统吃的资源差得很远：

- **纯静态博客**（Hexo、Hugo 本地生成后把文件传上去）：服务器只跑一个 Nginx，而 Nginx 本身只占 10–20MB 内存，512MB–1GB 的机器就能轻松应付；
- **WordPress**：要同时跑 PHP-FPM 和 MariaDB 数据库，单个站点最低 1GB 内存能跑，2GB 比较舒适；
- **Typecho**：国产轻量博客系统，对服务器要求比 WordPress 还低，1GB 机器毫无压力。

流量方面更不用担心。一篇图文博客页面按 1–2MB 算，1.5TB 月流量足够支撑日均几万次页面访问——个人博客的日常访问量离这个数还差着一两个数量级。图片多的话把媒体文件挪到对象存储或套上 CDN，源站流量还能再降一截。

所以选购思路很简单：先买小，不够再升。一个人写作的博客，1GB 是合格起点，2GB 是从容起点；超过 4GB 的配置，对纯博客来说都属于提前消费。

## 常见问题

**用境外 VPS 搭博客，域名需要备案吗？**
不需要。ICP 备案只针对服务器放在中国大陆的网站，RackNerd 的机房在美国，域名解析过去就能直接访问。

**1GB 内存跑 WordPress 真的够吗？**
够，前提是配缓存。装一个缓存插件把页面静态化后，数据库压力大幅下降，日均几千 PV 没有问题；再加 1–2GB swap 做保险更稳。要是插件装了二三十个，或者还想塞个论坛，那就老实上 2GB 以上。

**20GB 硬盘会被博客写满吗？**
系统本身占 3–5GB，纯文字博客一年也难写掉 10GB。图片多的博客建议把媒体文件放对象存储，源站只留程序和数据库，硬盘永远焦虑不起来。
